# Development scripts

`bridge_match_to_club.py` attaches an existing local video fixture to a private club console without re-running the video pipeline. From `academy-watch-backend/`, run `ALLOW_FIXTURE_BRIDGE=1 python scripts/dev/bridge_match_to_club.py --match-id 4 --manager-email mj@bywayofmj.com [--program-name "AFC Yorkies"] [--dry-run] [--allow-db-name fixture_copy]`. The script refuses production-like environments, Supabase/pooler hosts, and non-SQLite databases not named `soccer_newsletter` unless their exact name is explicitly allowed. It creates or reuses the fixture league/program/manager grant and local roster identities, assigning each approved local player its negative synthetic player id so club results can be recorded. Re-running is idempotent for fixture rows and links, but it deliberately re-approves/un-suspends the program and claim and reactivates the manager grant; this is a development repair tool. It prints the resulting member mapping plus `/my-club`. It is for development databases only; never run it against production.
