Ball truth — confirm or correct suggestions

Every visible ball counts. Normal labels default to match ball; review labels default to NOT the match ball. Enter/Space accepts a suggestion; click places a ball; N confirms no ball at all. M toggles match identity. C confirms the existing visible label as-is, NOT the match ball, preserving its coordinates and provenance. Arrows change frame; J/K change clip. Leave uncertain frames unlabelled. Suggestions never save themselves. Export JSONL as a backup.

Once v2 browser storage exists, the embedded seed is ignored. Before syncing a kit, export your current browser labels and run compare_label_exports.py against the original export; both steps are mandatory. If a kit was rebuilt from a fresh export, import that export here to update a browser that already opened build 10 or 11.
