# Frozen evidence data (local only)

This directory is generated by `../build_manifest.py`. Its 20 match clips and
truth files are evaluation-only club-owned data and must never be committed or
used for training.

From the repository root:

```sh
/Users/michaeljones/Projects/loanarmy/.loan/bin/python \
  spike/video-analysis/bench/build_manifest.py
```

The builder reads local match 4 and existing v8 artifacts through backend
helpers, then writes `manifest.json`, `clips/`, and `truth/`. The manifest's
`frozen_set_id` hashes the sorted truth filenames and bytes. Regenerating from
the same database/artifacts and Git revision should reproduce the same truth
set ID. Clip encoding may differ by ffmpeg build and is intentionally not part
of that ID.

Only this README and `manifest.example.json` belong in Git.
