# Dream-scorecard S3 tooling

- `s3-brief-common.md` is the shared S3 package brief header.
- `s3-contracts.md` freezes the cross-package contracts.
- `s3-p0-billing.md`, `s3-p1-scout-pro.md`, `s3-p2a-clubs.md`, and `s3-p3-web.md` are the package briefs.
- `credits/` freezes the GOL credits contracts and GC-P0/GC-P1 package briefs.
- `s3-checker-template.md` is the adversarial checker; `s3b1_preapply.sql`, `s3c1_preapply.sql`, and `s3d1_preapply.sql` plus their `prod_preapply_*` / `prod_stamp_*` scripts are the guarded migration tools.
