# GOL credits — contracts (GC-P0 provides; GC-P1 mocks these byte-for-byte). Read with ../s3-contracts.md (dark gate, error style, naive UTC). Critiqued by codex 2026-09-04 (33 fixes folded in).

## Env (read at call time)
`GOL_FREE_ALLOWANCE` (int, default 3); `STRIPE_PRICE_GOL_STARTER` + `GOL_STARTER_CREDITS` (positive int); `STRIPE_PRICE_GOL_TOPUP` + `GOL_TOPUP_CREDITS`. A pack is offered iff its price env is set AND its credits env is a positive int. **Packs are USD-only**: a pack whose Stripe price currency is not `usd` is NOT offered and is logged once (the ledger still stores `currency` for honesty).

## Catalog (`src/config/stripe_config.py`)
`PRODUCT_CATALOG["gol"] = {"scope_type":"user","name":"GOL chatbot","purchase_mode":"payment","packs":{"gol_starter":{"price_env":"STRIPE_PRICE_GOL_STARTER","credits_env":"GOL_STARTER_CREDITS","label":"Starter"},"gol_topup":{"price_env":"STRIPE_PRICE_GOL_TOPUP","credits_env":"GOL_TOPUP_CREDITS","label":"Top up"}}}`.
Entries without `prices` are IGNORED by `offered_products()`, `resolve_price()`, `product_for_price_id()` (today they index `product["prices"]` unconditionally — fix that); a missing `purchase_mode` means `subscription`. New: `offered_packs() -> dict[pack_id, {"price_id","credits","label"}]`. There is NO `pack_for_price_id` (starter and top-up may share a price): webhook grants resolve the pack from the LOCAL checkout row (`price_code == pack_id`), never from Stripe metadata or the price id.

## Model `GolCreditLedger` → `gol_credit_ledger` (append-only)
id; user_account_id FK user_accounts ON DELETE CASCADE NOT NULL; bucket String(20) NOT NULL CHECK IN ('free_allowance','prepaid'); kind String(20) NOT NULL CHECK IN ('grant','debit','reversal','adjustment'); delta Integer NOT NULL CHECK (delta <> 0); idempotency_key String(120) UNIQUE NOT NULL; debit_id Integer FK gol_credit_ledger.id (nullable; set on a question reversal → the debit it compensates); client_msg_id String(64); attempt Integer; stripe_event_id String(255); stripe_session_id String(255) UNIQUE (nullable; grants only); stripe_payment_intent_id String(255); pack_id String(40); amount_paid_cents Integer; currency String(3); refunded_cents Integer NOT NULL default 0 (grants only: cumulative cents Stripe has refunded against this grant — the ONE mutable column, updated under the user lock); note String(200); created_at DateTime NOT NULL naive UTC server_default now(). Indexes: (user_account_id, bucket), (stripe_payment_intent_id). Migration `s3d1` (down `s3c1`), guarded DDL, RLS on, no policies.
Balances: `credit_balance = Σ delta WHERE bucket='prepaid'` (may be negative); `free_questions_remaining = max(0, GOL_FREE_ALLOWANCE + Σ delta WHERE bucket='free_allowance')`.

## Service `src/services/gol_credits.py`
- `class CreditsExhausted(Exception)`: carries `free_questions_remaining`, `credit_balance`. `class ClientMsgIdReused(Exception)`.
- `balances(user) -> {"free_questions_remaining": int, "credit_balance": int}`.
- `reserve_question(user, client_msg_id, *, question_hash, role="user") -> {"bucket": "free_allowance"|"prepaid"|"exempt"|"disabled", "free_questions_remaining", "credit_balance", "debited": bool, "attempt": int|None}` — OWNS its commit. billing off → `disabled`, NO write, NO ledger query; role == "admin" → `exempt`, no write; else lock the user row (`select(UserAccount.id)…with_for_update()`; a no-op on SQLite — comment it), then: compute `question_hash = sha256(normalised message)` (route passes it); if the LATEST debit for (user, client_msg_id) has no matching reversal AND its stored `note` equals `question_hash` → return balances with `debited: false` (retry of the SAME in-flight/successful question); same id with a DIFFERENT hash → raise `ClientMsgIdReused` (route → 409 `{"error":"client_msg_id_reused"}`, no SSE bytes) — a client_msg_id is bound to one question for its lifetime; else `attempt = (max prior attempt or 0) + 1` and insert debit `idempotency_key = f"q:{user.id}:{client_msg_id}:{attempt}"`, free bucket if free > 0 else prepaid if credit_balance > 0 else raise `CreditsExhausted`. Insert races → catch IntegrityError under a savepoint, re-read, return `debited: false`.
- `refund_question(user, client_msg_id) -> bool` — OWNS its commit; under the user lock find the latest debit for (user, client_msg_id) with no reversal; insert `reversal` (+1, same bucket) with `debit_id` and `idempotency_key = f"refund:{debit_id}"`; false if none/already reversed.
- `grant_purchase(user, *, pack_id, credits, stripe_session_id, stripe_payment_intent_id, stripe_event_id, amount_paid_cents, currency)` — FLUSH ONLY (the webhook owns the commit); idempotent on `stripe_session_id` (unique) and `idempotency_key = f"grant:{stripe_session_id}"`; returns the grant row or the existing one.
- `apply_refund(*, payment_intent_id, cumulative_refunded_cents, stripe_event_id) -> int` — FLUSH ONLY; under the user lock find the grant by `stripe_payment_intent_id` (none → return 0 and let the event be `ignored`); `target = min(credits, floor(credits * cumulative_refunded_cents / amount_paid_cents))`; `to_reverse = target - Σ(existing reversals for this grant)`; if `to_reverse > 0` insert `reversal` (−to_reverse, prepaid) keyed `f"refund:{payment_intent_id}:{cumulative_refunded_cents}"`; ALWAYS set `grant.refunded_cents = max(grant.refunded_cents, cumulative_refunded_cents)`; returns to_reverse (0 allowed).
- `forfeit_for_deletion(user) -> dict` — see account deletion.

## Routes
- `POST /api/gol/chat` (`@require_user_auth` outermost; NEVER `require_billing_rail` here — dark must keep today's behaviour). Order: `data = request.get_json(silent=True)`; not a dict → 400 `{"error":"invalid_json"}`; validate `message`; when billing is on, `client_msg_id` REQUIRED (`^[A-Za-z0-9_-]{8,64}$`, else 400 `{"error":"invalid_client_msg_id"}`), when off optional/ignored; construct `GolService` (its 503 path stays BEFORE reservation so a failed init never debits); `reserve_question(...)`; `CreditsExhausted` → **402** `{"error":"credits_exhausted","feature":"gol_chat","free_questions_remaining":n,"credit_balance":n,"top_up_path":"/account/billing"}` before any SSE; else build the streaming Response. SSE: FIRST frame `event: usage` data `{"bucket":..,"free_questions_remaining":n,"credit_balance":n,"debited":bool}`. The route wraps the service generator: when the NEXT frame to forward is the service's terminal `error` event (or the route's own exception path produces one), call `refund_question` BEFORE yielding it, then yield the original `error` frame and one `event: usage` frame with `"refunded": true`; at most one compensation per reservation; a client disconnect (GeneratorExit) is NOT refunded. `require_scout_entitlement("gol_chat")` is REMOVED from chat and `export-pdf` (login stays; export never debits).
- `POST /api/billing/checkout` (`@require_user_auth`, 10/min): body is EITHER `{"pack_id","client_key"}` (payment) OR `{"product_code","price_code","client_key"}` (subscription); both or neither → 400 `{"error":"invalid_checkout_request"}`; unknown pack → 400 `{"error":"unknown_pack"}`. Service signature: `create_checkout(user, *, client_key, pack_id=None, product_code=None, price_code=None, scope_id=None)`. Payment branch: reuse ONLY an open `BillingCheckoutSession` with the SAME (`product_code="gol"`, `price_code=pack_id`, purchaser, client_key); an open row with the same client_key but a different pack → 409 `{"error":"client_key_conflict"}`; ignore unrelated open rows (no sibling expiry, no `already_subscribed`); Stripe idempotency key `checkout:gol:<pack_id>:<user.id>:<client_key>` (suffixed with the row's attempt timestamp when re-creating a Session for a locally expired row — same rule as the subscription branch); NO `allow_promotion_codes` on payment-mode Sessions (packs are fixed-price); a pack whose cached price currency is not `usd` → 400 `unknown_pack` at checkout (not only hidden from config); `mode="payment"`, one line item qty 1, `customer`, success/cancel URLs as today, `client_reference_id=<row id>`, `metadata` AND `payment_intent_data.metadata` = `{"kind":"credit_topup","product_code":"gol","pack_id","user_id","app":"academy_watch"}`, NO `subscription_data`. Row: product_code "gol", price_code = pack_id.
