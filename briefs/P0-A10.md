## The situation

PR review (codex, P1): the web app showed "Introductions" entry points (nav item, Scout Desk button + Introduce
icons, club console tab) even when the backend flag `CONTACT_RAIL_ENABLED` is off — then every `/api/contact/*`
route answers 404 and users walk into errors. P0-A10b added `GET /api/features` → `{"contact_rail": true|false}`.
This task reads it once per session (`src/lib/contact-flags.js` + `src/hooks/useContactRail.js`) and renders each
entry point only when the answer is `true`; `/introductions` itself shows an "not available right now" card when off.
