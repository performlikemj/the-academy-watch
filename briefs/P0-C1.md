# Task brief — P0-C1: `RequireAuth` must honor `requireJournalist`

**Pattern:** copy-adapt · **Thinking:** off · **Budget:** 45 min ·
**Files you will touch:** `academy-watch-frontend/src/App.jsx` (ONE function, ~7 lines at line 520)
and `academy-watch-frontend/tests/require-auth-journalist.test.mjs` (NEW). Nothing else.

## The situation

`App.jsx` line 4267 renders `<RequireAuth requireJournalist>` around the writer-editor route, but the
`RequireAuth` component (line 520) only accepts `children`. The prop is silently ignored, so the
client-side gate for the writer editor does not exist (the server still protects the API). Make the
prop real.

## The job

Replace the function at `academy-watch-frontend/src/App.jsx` lines 520-526. Current code, verbatim:

```jsx
function RequireAuth({ children }) {
  const { token } = useAuth()
  if (!token) {
    return <Navigate to="/" replace />
  }
  return children
}
```

New code, verbatim:

```jsx
function RequireAuth({ children, requireJournalist = false }) {
  const { token, isJournalist } = useAuth()
  if (!token) {
    return <Navigate to="/" replace />
  }
  if (requireJournalist && !isJournalist) {
    return <Navigate to="/" replace />
  }
  return children
}
```

Known facts — do not re-discover them:
- `useAuth()` already returns `isJournalist` (see `src/context/AuthContext.jsx`: the context default
  has `isJournalist: false`, and `src/context/buildAuthSnapshot.js` fills it).
- `Navigate` is already imported in App.jsx (the function uses it today).
- The call site at line 4267 already passes `requireJournalist`. Do not touch it.

## The test — write it FIRST

Create `academy-watch-frontend/tests/require-auth-journalist.test.mjs`. This repo's frontend unit tests
are plain `node --test` and often check source text (example: `tests/admin-sidebar-responsive.test.mjs`).
Copy this exactly:

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import fs from 'node:fs/promises'

const appFile = new URL('../src/App.jsx', import.meta.url)

test('RequireAuth accepts and enforces requireJournalist', async () => {
  const src = await fs.readFile(appFile, 'utf8')
  const start = src.indexOf('function RequireAuth(')
  assert.notEqual(start, -1, 'RequireAuth must exist in App.jsx')

```
