## The situation

`club_registry._table_columns(table)` asks the database for a table's column names with a SQLAlchemy
inspector (2 catalog queries). It is called from 13 places, up to a dozen times inside ONE contact-rail
request. The schema cannot change in the middle of a request, so introspect ONCE per HTTP request and
reuse. Outside a request (scheduled jobs) keep the current behaviour — no cache.

Two things must keep working unchanged: (a) `tests/test_contact.py:2124` monkeypatches
`src.services.club_registry._table_columns` — so that name must remain the function every caller uses;
(b) everything else in the file.
