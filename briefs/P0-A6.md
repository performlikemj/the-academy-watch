## The situation

Scouts send introductions; players receive them. Both live on the same account type, so ONE page with
two tabs serves both: **Sent** (`box=sent`) lists what I sent (withdraw while pending), **Inbox**
(`box=inbox`) lists what I received (accept / decline while pending). Selecting a row opens the
`ContactThread` beside the list. The API:

- `GET /api/contact/requests?box=sent|inbox&limit&offset` → `{ requests: [contact_request…], box, total,
  limit, offset }` (shape of `contact_request` is in `briefs/P0-A6b.md`).
- `POST …/<id>/accept`, `…/decline`, `…/withdraw` → `{ contact_request }`; 409 with `{ error }` when
  the state no longer allows it.
