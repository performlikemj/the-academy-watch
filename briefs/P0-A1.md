# Task brief — P0-A1: club-consent email links must open the web page, not the API

**Pattern:** surgical fix · **Thinking:** off · **Budget:** 30 min ·
**Files you will touch:** `academy-watch-backend/src/services/contact.py` (ONE line in ONE function)

## The situation

When a verified scout asks to contact a contracted player whose club is on the platform, the club's
manager gets an email with two links (grant / decline). Today those links are built as
`https://theacademywatch.com/api/contact/club-consent/<token>`. That host is the web app: Azure
Static Web Apps rewrites every unknown path to `index.html`, and the React app has no such route, so
the club sees a blank page and can never answer. The API route `/api/contact/club-consent/<token>`
stays exactly as it is. The EMAIL must link to the web page `/contact/club-consent/<token>` (that page
is built in a later task and will call the API).

## The job

In `academy-watch-backend/src/services/contact.py`, lines 238-245 are, verbatim:

```python
def club_consent_action_links(contact_request_id: str) -> dict[str, str]:
    base = (os.getenv("PUBLIC_BASE_URL") or "https://theacademywatch.com").strip().rstrip("/")
    path = "/api/contact/club-consent/"
    return {
        action: f"{base}{path}{issue_club_consent_token(contact_request_id, action)}" for action in ("grant", "decline")
    }
```

Change ONE line: `    path = "/api/contact/club-consent/"` becomes `    path = "/contact/club-consent/"`.
