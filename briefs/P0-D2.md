## The situation

Admin reviewers stream a match in the browser through `GET /api/admin/video/matches/<id>/footage?token=…`.
The `token` is a media token that lives **30 minutes** (`MEDIA_TOKEN_TTL = 60 * 30` in `src/auth.py`).
In production that route answers with a 302 to an Azure Blob read-SAS URL minted for **6 hours**
(`READ_SAS_HOURS = 6`, used by the worker's multi-hour footage pull) — so anyone who captures the redirect
target keeps hours of access to youth footage after the token died, and the redirect carries no
`Cache-Control`. Mint a separate, short read SAS for the browser path and mark the redirect `no-store`.
The worker's 6-hour SAS stays exactly as it is.

`mint_read_sas` (around line 82) is, verbatim:

```python
def mint_read_sas(blob_path: str, hours: int = READ_SAS_HOURS) -> str:
    """Read-only SAS URL (worker footage pull, report thumbnails)."""
    expiry = datetime.now(UTC) + timedelta(hours=hours)
    sas = _mint_sas(blob_path, BlobSasPermissions(read=True), expiry)
    client = _service_client()
    return f"{client.url}{_container()}/{blob_path}?{sas}"
```

Add this function directly BELOW it (two blank lines between):

```python
def mint_media_read_sas(blob_path: str, minutes: int = MEDIA_READ_SAS_MINUTES) -> str:
    """Short read-only SAS for the browser footage redirect — never longer than the media token."""
    expiry = datetime.now(UTC) + timedelta(minutes=minutes)
    sas = _mint_sas(blob_path, BlobSasPermissions(read=True), expiry)
    client = _service_client()
    return f"{client.url}{_container()}/{blob_path}?{sas}"
```

        if not match.blob_path:
