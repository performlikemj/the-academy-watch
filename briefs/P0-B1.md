## The situation

The club console can create matches (`POST /club/<id>/matches`) and read one
(`GET /club/<id>/matches/<match_id>`) but cannot LIST them, so the web console keeps match ids in the
browser's localStorage and a manager on a second device sees an empty history. Add the list endpoint
(newest first; no paging — quota caps a program at 100 rows). The console switch is a later task.
